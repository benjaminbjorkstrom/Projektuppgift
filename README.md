# La Casa Ristorante

## Om projektet
La Casa Ristorante är ett projekt där en webbplats för en fiktiv italensk restaurang har designats och utvecklats med hjälp av HTML, CSS och JavaScript. Webbplatsen är byggd med en elegant stil med varma färger på ett användarvänligt sätt. Webbplatsen gör det enkelt för besökare att hitta information om restaurangen, se menyn och kontakta restaurangen.

## Projektstruktur
* index.html - Startsida
* kontakt.html - Kontaktsida med information och formulär
* meny.html - menysida för restaurangen
* css/style.css - Utseende och layout för webbplatsen
* js/main.js - formulärvalidering och navigation
* images/ - bilder som används på webbplatsen
* design/ - Wireframes och mockups för webbplatsen

## Tekniker
* HTML
* CSS

* Figma 
* Git och Github

## Funktioner
* Startsida för webbplatsen med information om restaurangen och vidare navigering för övriga siidor.
* Menysida med maträtter samt beskrvningar och priser.
* Kontaktsida/bordsbokning med kontaktinformation och kontaktformulär samt boka bord möjligheter.
* Responsiv design anpassad för olika skärmar, både mobil och dator samt Ipad.
* Mobilanpassad navigering med hamburgarmeny.
* JavaScript validering av kontatkformulär samt mobilmeny för mobilanpassning.
